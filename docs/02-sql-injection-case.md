#### **পর্ব ২: ম্যানুয়াল কোড রিভিউ ও লাইভ এক্সপ্লয়েট (২৫ -- ৫৫ মিনিট)**

**কেস ১: Django ORM বনাম Raw SQL Injection (/sql_lab) --- [২৫--৪০
মিনিট]**

**ORM ফিল্টার** হলো ডেটাবেস থেকে তথ্য খোঁজা বা ফিল্টার করার একটি নিরাপদ ও
আধুনিক প্রোগ্রামিং পদ্ধতি।

**ORM**-এর পূর্ণরূপ হলো **Object-Relational Mapping**। সাধারণ ডেটাবেস ভাষায়
যেখানে কাঁচা কুয়েরি (Raw SQL যেমন: SELECT * FROM users WHERE...) লিখতে
হয়, ORM ব্যবহার করলে প্রোগ্রামিং ভাষার নিজস্ব সিনট্যাক্স দিয়ে অবজেক্ট আকারে
ডেটাবেসের সাথে কাজ করা যায়।

### **১. সাধারণ SQL কুয়েরি বনাম ORM ফিল্টার**

**সাধারণ Raw SQL (ঝুঁকিপূর্ণ):**

```python
# ইউজার ইনপুট সরাসরি জোড়া লাগানো হচ্ছে (SQL Injection হওয়ার সম্ভাবনা থাকে)
sql_query = "SELECT * FROM login WHERE user='" + name + "'"
```

**Django ORM ফিল্টার (নিরাপদ):**

```python
# Django ORM-এর নিজস্ব ফিল্টার মেথড
login.objects.filter(user=name)
```

### **২. এটি কেন নিরাপদ?**

-   **স্বয়ংক্রিয় Parameterization:** আপনি যখন .filter(user=name) ব্যবহার
    > করেন, তখন Django বা ORM ফ্রেমওয়ার্ক ইউজারের দেওয়া ইনপুটকে সরাসরি
    > কুয়েরির ভেতর বসায় না।

-   **কোড বনাম ডেটা পার্থক্যকরণ:** এটি ইনপুটকে আলাদা "প্যারামিটার" হিসেবে
    > ডেটাবেসে পাঠায়। ফলে ইনপুটে যদি কোনো ক্ষতিকর হ্যাকিং কোড (যেমন: ' OR
    > '1'='1) থাকেও, ডেটাবেস সেটিকে এক্সিকিউটেবল কোড না ভেবে কেবল
    > সাধারণ টেক্সট (Plain text) হিসেবে বিবেচনা করে। এতে **SQL
    > Injection** আক্রমণ প্রতিহত হয়।

**কোড দেখানো (introduction/views.py): এডিটরে sql_lab ফাংশনটি ওপেন করে
দেখান:**

```python
name = request.POST.get('name')
password = request.POST.get('pass')
if name:
    # এখানে ডেভেলপার নিরাপদ Django ORM ব্যবহার করেছে:
    if login.objects.filter(user=name):
        # কিন্তু পরের লাইনেই পাসওয়ার্ড চেক করতে গিয়ে Raw SQL-এ জোড়া লাগিয়েছে (Sink!):
        sql_query = "SELECT * FROM introduction_login WHERE user='"+name+"' AND password='"+password+"'"
        val = login.objects.raw(sql_query)
```

**৩টি প্রশ্ন প্রয়োগ:**

-   **Source: request.POST.get('pass')**

-   **Sink: login.objects.raw(sql_query)**

-   **Guard: ইউজারনেমে ORM ফিল্টার থাকলেও পাসওয়ার্ড ফিল্ডে কোনো গার্ড বা
    > Parameterization নেই!**

### **সমাধান: Django Shell দিয়ে একদম নিশ্চিতভাবে ইউজার তৈরি করা**

১. টার্মিনালে আপনার ভার্চুয়াল এনভায়রনমেন্ট (source pygoat-venv/bin/activate)

```bash
python manage.py shell
```

২. শেল চালু হলে (>>> দেখা গেলে) নিচের কমান্ডগুলো এক এক করে লিখে এন্টার
চাপুন:

```python
from introduction.models import login
# আগের কোনো ভুল এন্ট্রি থাকলে মুছে ফেলা
login.objects.filter(user='admin').delete()
# একদম নতুন ফ্রেশ ইউজার তৈরি করা
login.objects.create(user='admin', password='password123')
exit()
```
